# Privacy

Lore reads public GitHub data only: pull requests, reviews, issues and comments of the repo you type in. It calls GitHub's public API from your browser, without a token.

It keeps GitHub logins and nothing else about people: no emails, no names.

A repo you load is stored in your own Anna app storage for 24 hours, so opening it again doesn't call GitHub. The list of repos you loaded is stored there too. Nobody else can see either.

Questions you ask in the Ask tab, and issues you triage, go to the model you use in Anna, with the parts of the repo's history the answer needs. Lore has no server of its own and collects nothing.

Questions: https://github.com/JannetEkka/anna-lore/issues
